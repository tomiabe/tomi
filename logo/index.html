I use my own public GitHub activity across all my public repositories, not only this site's repo. Each event's repository chooses where its dent lands, and the commit count decides how deep it goes. Private commits aren't visible in GitHub's public events API, and only roughly the last 90 days are available. While the page is open, I check for fresh activity every couple of minutes. If GitHub isn't reachable, it falls back to the time of day in Sydney.

How it's built

  1. A small script traces the PNG mark into two vector outlines: the shape and the triangular cut-out.
  2. In the browser, those outlines are resampled into a few hundred points, evenly spaced around their edges.
  3. Each public event is given a position on the outline from a hash of its repository name, and a depth from its commit count or event type. Older events fade.
  4. Those positions push points in or out along a smooth curve, and the result is joined back into one SVG path.
  5. The Motion switcher offers three readings of the same data: Still (no idle movement, the default), Ripple (one wave travels around the mark on a new event), and Pulse (a slow breath that calms with time).
  6. “Compare with original” lays a pale, dashed silhouette of the untouched PNG behind the mark so you can see how far it has shifted.

It is deliberately quiet: a pause button, a respect for reduced-motion settings, and a static fallback if scripting is unavailable. The motion choice is remembered.
